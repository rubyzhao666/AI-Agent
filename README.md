# SOLO AI 工作流手册

**8 大岗位 × 5 高频任务的 AI 工作流与 Prompt 手册**

为全行业职场人提供标准化 AI 工作流：岗位选择 → 任务识别 → 工作流生成 → Prompt 优化 → 执行指南。每个任务包含完整的任务定义、SOLO 工作流步骤、可直接复制的最优 Prompt、提效数据和注意事项。

## 🎯 快速使用

1. 从上表找到你的岗位，点进对应文件
2. 找到目标任务，复制「最优 Prompt」
3. 替换 `{占位符}` 为你的实际信息
4. 粘贴到任意大模型（ChatGPT / Claude 等）中执行

进阶技巧（Prompt 组合、迭代优化、个性化定制）见 [使用指南](docs/usage-guide.md)。

## 🔧 单任务标准结构

每个任务按统一模板编写：

- **📌 任务定义**：场景描述、输入要求、输出标准
- **🤖 SOLO 工作流**：分步操作步骤
- **💡 最优 Prompt**：完整可复制的 Prompt 模板
- **📈 提效数据**：时间节省与质量提升
- **⚠️ 注意事项**：常见坑与规避方法

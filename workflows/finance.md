# 财务 · AI 工作流（5 大核心任务）

## 任务1：财务报表分析

### 📌 任务定义
- **场景描述**：月度/季度/年度财务分析、经营分析会
- **输入要求**：财务报表数据、同比环比数据、行业对标
- **输出标准**：财务分析报告 + 经营建议

### 🤖 SOLO工作流
1. **数据整理**：提取关键财务指标
2. **趋势分析**：分析指标变化趋势
3. **结构分析**：分析收入成本结构
4. **比率分析**：计算财务比率
5. **建议输出**：给出经营改进建议

### 💡 最优Prompt
```
作为财务分析专家，请帮我完成财务报表分析报告。

【分析期间】
- 报告期间：{如2024年Q1}
- 对比期间：{如2023年Q1、2023年Q4}

【财务数据】
请提供以下报表数据：
1. 资产负债表关键数据
2. 利润表关键数据
3. 现金流量表关键数据

{可粘贴数据表格或描述关键数据}

【分析要求】
请从以下维度进行分析：
1. 盈利能力分析（毛利率、净利率、ROE等）
2. 偿债能力分析（资产负债率、流动比率等）
3. 营运能力分析（周转率指标）
4. 成长能力分析（收入/利润增长率）
5. 现金流分析

请输出：
1. 执行摘要（核心结论）
2. 整体经营情况
3. 详细财务分析（各维度分析+数据图表建议）
4. 同比/环比分析
5. 风险提示
6. 经营建议

格式：Markdown，数据呈现清晰，专业术语准确。
```

### 📈 提效数据
- **传统耗时**：4-8小时
- **AI辅助耗时**：1-1.5小时
- **效率提升**：80%
- **质量提升**：分析更全面，洞察更深入

## 任务2：预算编制方案

### 📌 任务定义
- **场景描述**：年度预算编制、季度预算调整、项目预算
- **输入要求**：历史数据、业务计划、战略目标
- **输出标准**：完整预算方案 + 编制说明

### 🤖 SOLO工作流
1. **目标确认**：明确预算编制目标
2. **历史分析**：分析历史预算执行情况
3. **业务对接**：收集各部门预算需求
4. **预算编制**：编制收入/成本/费用预算
5. **平衡调整**：预算平衡和审批

### 💡 最优Prompt
```
作为财务预算专家，请帮我编制预算方案。

【预算信息】
- 预算类型：{年度预算/季度预算/项目预算}
- 预算期间：{如2024年度}
- 编制方法：{零基预算/增量预算/滚动预算}

【业务计划】
{描述下一年度的业务计划和目标}

【历史数据】
{提供历史预算执行数据，如：
- 上年度预算：{金额}
- 上年度实际：{金额}
- 预算执行率：{百分比}
}

【关键假设】
{如收入增长率、成本变动、人员增长等}

请输出完整预算方案：
1. 预算编制说明（编制依据、假设条件）
2. 收入预算（分产品/渠道/区域）
3. 成本预算（分成本项目）
4. 费用预算（分部门/费用类型）
5. 资本支出预算
6. 现金流量预算
7. 预算汇总表
8. 关键指标预算（收入、利润、现金流等）

格式：Markdown，表格清晰，逻辑严密。
```

### 📈 提效数据
- **传统耗时**：16-40小时
- **AI辅助耗时**：3-4小时
- **效率提升**：85%
- **质量提升**：预算更合理，执行偏差降低30%

## 任务3：成本分析报告

### 📌 任务定义
- **场景描述**：成本控制、降本增效、定价决策
- **输入要求**：成本数据、业务量数据、成本动因
- **输出标准**：成本分析报告 + 优化建议

### 🤖 SOLO工作流
1. **成本归集**：整理各项成本数据
2. **成本分类**：区分固定/变动、直接/间接成本
3. **成本分析**：分析成本结构和变动
4. **动因分析**：识别成本驱动因素
5. **优化建议**：提出降本增效方案

### 💡 最优Prompt
```
作为成本管理专家，请帮我完成成本分析报告。

【分析背景】
- 分析目的：{如成本控制/定价决策/降本增效}
- 分析范围：{产品/部门/项目}
- 分析期间：{时间范围}

【成本数据】
{提供成本数据，如：
| 成本项目 | 本期金额 | 上期金额 | 变动率 |
|----------|----------|----------|--------|
| {项目1} | {金额} | {金额} | {比率} |
}

【业务数据】
{提供相关业务量数据，如产量、销量、工时等}

请输出：
1. 执行摘要
2. 成本结构分析（成本构成及占比）
3. 成本变动分析（同比/环比变化及原因）
4. 成本动因分析（影响成本的关键因素）
5. 单位成本分析（单位产品成本变化）
6. 成本对标分析（与行业/历史对标）
7. 问题诊断
8. 降本增效建议（具体措施+预期效果）

格式：Markdown，数据清晰，建议可执行。
```

### 📈 提效数据
- **传统耗时**：6-12小时
- **AI辅助耗时**：1-2小时
- **效率提升**：85%
- **质量提升**：分析更深入，降本措施更精准

## 任务4：税务筹划方案

### 📌 任务定义
- **场景描述**：年度税务规划、业务模式优化、税务风险评估
- **输入要求**：业务情况、税务现状、政策环境
- **输出标准**：合规税务筹划方案

### 🤖 SOLO工作流
1. **现状梳理**：分析当前税务情况
2. **政策研究**：梳理适用税收优惠政策
3. **风险识别**：识别税务风险点
4. **方案设计**：设计合规筹划方案
5. **效果测算**：测算节税效果

### 💡 最优Prompt
```
作为税务专家，请帮我制定税务筹划方案。

【企业情况】
- 企业类型：{如有限责任公司}
- 行业：{行业}
- 规模：{如年收入、员工人数}
- 所在地：{注册地}

【税务现状】
- 主要税种：{增值税、企业所得税等}
- 税负情况：{各税种税负率}
- 优惠政策：{目前享受的优惠政策}

【业务特点】
{描述业务模式和特点}

请输出：
1. 税务现状分析
2. 适用税收优惠政策梳理
3. 税务风险识别
4. 税务筹划方案（合规前提下的优化建议）
5. 节税效果测算
6. 实施建议与注意事项

重要提示：所有建议须在法律法规允许范围内，确保合规性。

格式：Markdown，专业准确。
```

### 📈 提效数据
- **传统耗时**：8-16小时
- **AI辅助耗时**：2-3小时
- **效率提升**：80%
- **质量提升**：方案更合规，风险识别更全面

## 任务5：审计底稿整理

- **输入要求**：审计范围、重点事项、资料清单
- **输出标准**：规范审计底稿

### 🤖 SOLO工作流
1. **范围确定**：明确审计范围和重点
2. **资料清单**：编制资料需求清单
3. **底稿编制**：按标准格式编制底稿
4. **交叉复核**：检查底稿完整性
5. **归档整理**：规范归档

### 💡 最优Prompt

作为审计专家，请帮我整理审计底稿。

【审计信息】

【重点事项】
{列出审计重点关注事项}

【已获取资料】
{列出已获取的资料清单}

请输出：
1. 审计计划（审计目标、范围、重点、时间安排）
2. 资料需求清单
3. 审计程序表（按审计循环列示）

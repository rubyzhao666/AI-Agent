# 销售 · AI 工作流（5 大核心任务）

## 任务1：客户需求分析

### 📌 任务定义
- **场景描述**：客户拜访前、方案设计前、销售推进中
- **输入要求**：客户背景、沟通记录、行业信息
- **输出标准**：客户需求分析报告

### 🤖 SOLO工作流
1. **信息收集**：收集客户背景信息
2. **需求挖掘**：分析客户痛点和需求
3. **决策分析**：分析决策链和决策因素
4. **方案匹配**：匹配解决方案
5. **策略制定**：制定销售策略

### 💡 最优Prompt
```
作为销售专家，请帮我完成客户需求分析。

【客户信息】
- 客户名称：{公司名称}
- 行业：{行业}
- 规模：{员工数/营收规模}
- 所处阶段：{初创/成长/成熟}

【关键联系人】
{决策者、影响者、使用者信息}

【已知需求】
{从沟通中了解到的需求信息}

【竞争情况】
{竞品参与情况}

请输出：
1. 客户背景分析
   - 公司业务分析
   - 行业趋势分析
   - 痛点假设

2. 需求分析
   - 显性需求
   - 隐性需求
   - 需求优先级

3. 决策链分析
   - 决策者画像
   - 决策流程
   - 关键决策因素

4. 竞争分析
   - 竞品优劣势
   - 我方差异化优势

5. 销售策略建议
   - 切入点
   - 关键动作
   - 风险点

格式：Markdown，分析深入，策略可执行。
```

### 📈 提效数据
- **传统耗时**：2-4小时
- **AI辅助耗时**：30-45分钟
- **效率提升**：80%
- **质量提升**：分析更深入，策略更精准

## 任务2：销售提案PPT

### 📌 任务定义
- **场景描述**：客户提案、方案汇报、投标演示
- **输入要求**：客户需求、解决方案、案例资料
- **输出标准**：完整提案PPT大纲 + 内容

### 🤖 SOLO工作流
1. **需求对齐**：确认客户核心关注点
2. **结构设计**：设计PPT逻辑框架
3. **内容撰写**：撰写各页核心内容
4. **案例匹配**：匹配相关成功案例
5. **优化打磨**：优化表达和视觉效果

### 💡 最优Prompt
```
作为销售提案专家，请帮我设计销售提案PPT。

【客户信息】
- 客户名称：{公司名称}
- 行业：{行业}
- 关键决策者：{职位和关注点}

【客户需求】
{客户的核心需求和痛点}

【我方方案】
{我们的解决方案和优势}

【成功案例】
{相关行业案例}

请输出：
1. PPT整体结构（页数建议15-20页）
2. 各页详细内容
   - 页码
   - 标题
   - 核心内容
   - 视觉建议

建议结构：
- 封面
- 目录
- 客户需求理解
- 解决方案概述
- 方案详细说明
- 成功案例
- 实施计划
- 投资回报
- 我们的优势
- 合作建议
- 附录

格式：Markdown，内容可直接用于PPT制作。
```

### 📈 提效数据
- **传统耗时**：4-8小时
- **AI辅助耗时**：1-1.5小时
- **效率提升**：80%
- **质量提升**：逻辑更清晰，说服力更强

## 任务3：商务谈判话术

### 📌 任务定义
- **场景描述**：价格谈判、合同谈判、异议处理
- **输入要求**：谈判目标、底线、对方情况
- **输出标准**：谈判策略 + 话术库

### 🤖 SOLO工作流
1. **目标设定**：确定谈判目标和底线
2. **对方分析**：分析对方立场和利益
3. **策略设计**：设计谈判策略和节奏
4. **话术准备**：准备各类场景话术
5. **预案准备**：准备应对方案

### 💡 最优Prompt
```
作为商务谈判专家，请帮我准备谈判话术。

【谈判背景】
- 谈判类型：{如价格谈判/合同谈判/合作条款}
- 谈判对象：{对方公司和关键人物}
- 谈判历史：{之前的沟通情况}

【我方立场】
- 目标：{期望达成的目标}
- 底线：{不可让步的底线}
- 可交换条件：{可以用来交换的条件}

【对方情况】
- 对方诉求：{对方的主要诉求}
- 对方痛点：{对方的压力和痛点}
- 对方决策者：{决策者特点和关注点}

请输出：
1. 谈判策略
   - 开场策略
   - 中场策略
   - 收尾策略

2. 话术库
   - 开场话术
   - 异议处理话术（价格异议、竞品比较、决策拖延等）
   - 价值塑造话术
   - 让步话术
   - 成交话术

3. 应对预案
   - 对方强硬时的应对
   - 对方要求降价时的应对
   - 谈判僵局时的应对

格式：Markdown，话术可直接使用。
```

### 📈 提效数据
- **传统耗时**：2-4小时
- **AI辅助耗时**：30-45分钟
- **效率提升**：80%
- **质量提升**：准备更充分，应变能力更强

## 任务4：客户跟进记录

### 📌 任务定义
- **场景描述**：客户拜访后、日常跟进、销售复盘
- **输入要求**：沟通内容、客户反馈、下一步计划
- **输出标准**：标准化跟进记录

### 🤖 SOLO工作流
1. **信息记录**：记录沟通关键信息
2. **需求更新**：更新客户需求理解
3. **问题识别**：识别阻碍和风险
4. **计划制定**：制定下一步行动
5. **提醒设置**：设置跟进提醒

### 💡 最优Prompt
```
请帮我整理客户跟进记录。

【基本信息】
- 客户名称：{公司名称}
- 联系人：{姓名和职位}
- 跟进日期：{日期}
- 沟通方式：{电话/拜访/邮件/微信}

【沟通内容】
{描述本次沟通的主要内容}

【客户反馈】
{记录客户的反馈和态度}

【待解决问题】
{需要解决的问题}

请输出标准化跟进记录：
1. 沟通摘要（3-5条要点）
2. 客户需求更新
3. 客户态度评估（积极/中立/消极）
4. 问题清单
5. 下一步行动计划（具体动作+责任人+时间）
6. 风险提示
7. 需要支持的事项

格式：Markdown，结构清晰，便于CRM录入。
```

### 📈 提效数据
- **传统耗时**：30分钟-1小时
- **AI辅助耗时**：5-10分钟
- **效率提升**：85%
- **质量提升**：记录更完整，跟进更及时

## 任务5：销售预测报告

### 📌 任务定义
- **场景描述**：月度/季度预测、业绩复盘、资源规划
- **输入要求**：商机数据、历史数据、市场情况
- **输出标准**：销售预测报告 + 分析建议

### 🤖 SOLO工作流
1. **数据汇总**：汇总商机和业绩数据
2. **漏斗分析**：分析销售漏斗各环节
3. **预测计算**：计算预测成交金额
4. **风险识别**：识别达成风险
5. **建议输出**：给出行动建议

### 💡 最优Prompt
```
作为销售运营专家，请帮我完成销售预测报告。

【预测周期】
- 预测期间：{如2024年Q2}
- 当前日期：{日期}

【商机数据】
{提供商机数据，如：
| 阶段 | 商机数 | 金额 | 转化率 |
|------|--------|------|--------|
| 初步接触 | X | Y万 | Z% |
| 需求确认 | X | Y万 | Z% |
| 方案报价 | X | Y万 | Z% |
| 商务谈判 | X | Y万 | Z% |
}

【历史数据】
{历史同期数据和历史预测准确率}

【目标情况】
- 周期目标：{目标金额}
- 已完成：{已完成金额}
- 差距：{差距金额}

请输出：
1. 执行摘要
2. 业绩概览
   - 目标完成情况
   - 同比/环比分析
   
3. 商机漏斗分析
   - 各阶段商机分布
   - 漏斗健康度评估
   
4. 预测分析
   - 预测成交金额
   - 预测置信区间
   - 预测依据
   
5. 风险识别
   - 达成风险
   - 重点商机风险
   
6. 行动建议
   - 重点跟进商机
   - 需要的支持
   - 资源调配建议

格式：Markdown，数据清晰，建议可执行。
```

### 📈 提效数据
- **传统耗时**：3-6小时
- **AI辅助耗时**：45分钟-1小时
- **效率提升**：80%
- **质量提升**：预测更准确，分析更深入

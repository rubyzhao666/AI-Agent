# 运营 · AI 工作流（5 大核心任务）

## 任务1：活动策划方案

### 📌 任务定义
- **场景描述**：节日营销、用户增长、品牌活动、促销活动
- **输入要求**：活动目标、预算范围、时间节点、资源情况
- **输出标准**：完整活动策划案（目标-创意-执行-预算-预期）

### 🤖 SOLO工作流
1. **目标明确**：确定活动核心KPI
2. **创意发散**：AI辅助生成活动创意方向
3. **方案细化**：完善执行细节和时间表
4. **预算编制**：资源分配和成本测算
5. **风险预案**：识别风险点和备选方案

### 💡 最优Prompt
```
作为资深运营专家，请帮我策划一场完整的运营活动。

【活动背景】
- 活动类型：{如节日营销/用户增长/品牌活动}
- 时间节点：{活动时间}
- 目标用户：{用户群体描述}

【活动目标】
- 核心KPI：{如新增用户X万/GMV X万}
- 次要指标：{如参与率、转化率、复购率}

【资源情况】
- 预算范围：{预算金额}
- 可用渠道：{如APP推送、短信、社群、公众号等}
- 支持资源：{如设计、开发、客服支持情况}

【竞品参考】
{如有参考案例，请描述}

请输出完整活动策划案：
1. 活动主题与创意概念
2. 活动玩法机制（详细规则）
3. 用户参与路径图
4. 推广渠道策略
5. 执行时间表（甘特图格式）
6. 预算分配表
7. 预期效果与ROI测算
8. 风险预案

要求：可执行性强，细节完整，可直接落地。
```

### 📈 提效数据
- **传统耗时**：8-16小时
- **AI辅助耗时**：1.5-2小时
- **效率提升**：85%
- **质量提升**：创意更丰富，执行细节更完善

## 任务2：内容创作生产

### 📌 任务定义
- **场景描述**：公众号推文、短视频脚本、产品文案、社媒内容
- **输入要求**：内容主题、目标受众、发布渠道、调性要求
- **输出标准**：可直接发布的内容成品

### 🤖 SOLO工作流
1. **选题策划**：确定内容方向和角度
2. **大纲生成**：AI辅助构建内容框架
3. **内容撰写**：分段落生成正文内容
4. **优化润色**：调整语言风格和可读性
5. **格式适配**：适配不同渠道的发布格式

### 💡 最优Prompt
```
作为内容运营专家，请帮我创作一篇高质量内容。

【内容类型】
{如公众号推文/短视频脚本/产品文案/小红书笔记}

【内容主题】
{描述要创作的主题}

【目标受众】
- 用户画像：{年龄、职业、兴趣等}
- 痛点需求：{用户关心什么}
- 阅读场景：{在什么场景下阅读}

【内容要求】
- 调性风格：{如专业/轻松/幽默/感性}
- 篇幅要求：{字数或时长}
- 核心信息：{必须传达的关键信息}
- CTA目标：{如关注/购买/分享/评论}

【参考素材】
{如有参考资料，请粘贴或描述}

请输出：
1. 标题备选（3-5个）
2. 内容大纲
3. 完整正文
4. 配图建议
5. 发布优化建议（如发布时间、话题标签等）
```

### 📈 提效数据
- **传统耗时**：2-4小时
- **AI辅助耗时**：20-40分钟
- **效率提升**：80%
- **质量提升**：内容结构更优，创意角度更多元

## 任务3：用户增长策略

### 📌 任务定义
- **场景描述**：新用户获取、老用户激活、用户留存提升
- **输入要求**：当前数据、增长目标、可用资源、竞品情况
- **输出标准**：增长策略方案 + 执行计划

### 🤖 SOLO工作流
1. **现状诊断**：分析当前增长瓶颈
2. **策略设计**：设计增长杠杆和玩法
3. **渠道规划**：确定获客渠道和投放策略
4. **实验设计**：设计A/B测试方案
5. **指标体系**：建立增长监测指标

### 💡 最优Prompt
```
作为用户增长专家，请帮我制定增长策略方案。

【产品信息】
- 产品名称：{产品名称}
- 产品类型：{如电商/内容/工具/SaaS}
- 核心功能：{一句话描述}

【当前数据】
- DAU/MAU：{数据}
- 新增用户：{日均新增}
- 留存率：{次日/7日/30日留存}
- 转化漏斗：{各环节转化率}

【增长目标】
- 时间周期：{如Q2}
- 目标指标：{如MAU增长50%}

【资源情况】
- 预算：{预算范围}
- 团队：{团队配置}
- 渠道：{可用渠道资源}

请输出完整增长策略：
1. 增长诊断（当前瓶颈分析）
2. 增长模型（AARRR各环节策略）
3. 获客策略（渠道+玩法+预算分配）
4. 激活策略（新用户Onboarding方案）
5. 留存策略（用户分层运营方案）
6. 变现策略（转化提升方案）
7. 实验计划（A/B测试优先级）
8. 指标监测体系

格式：Markdown，包含表格和流程图建议。
```

### 📈 提效数据
- **传统耗时**：12-24小时
- **AI辅助耗时**：2-3小时
- **效率提升**：85%
- **质量提升**：策略更系统，可执行性更强

## 任务4：数据复盘报告

### 📌 任务定义
- **场景描述**：活动结束复盘、周/月度运营复盘、项目总结
- **输入要求**：活动数据、执行过程、问题记录、对比基准
- **输出标准**：结构化复盘报告 + 改进建议

### 🤖 SOLO工作流
1. **数据汇总**：整理核心指标达成情况
2. **过程回顾**：梳理执行过程中的关键事件
3. **归因分析**：分析成功/失败原因
4. **经验提炼**：总结可复用的方法论
5. **改进计划**：制定下一步优化方向

### 💡 最优Prompt
```
作为运营分析专家，请帮我完成一份复盘报告。

【复盘对象】
- 项目/活动名称：{名称}
- 时间范围：{开始} 至 {结束}
- 复盘类型：{活动复盘/周期复盘/项目复盘}

【目标与实际】
| 指标 | 目标值 | 实际值 | 达成率 |
|------|--------|--------|--------|
| {指标1} | {值} | {值} | {值} |
| {指标2} | {值} | {值} | {值} |

【执行过程】
{描述关键执行节点和过程}

【问题记录】
{记录过程中遇到的问题}

请输出复盘报告：
1. 执行摘要（核心结论）
2. 数据复盘（各指标详细分析）
3. 过程复盘（关键节点回顾）
4. 归因分析（成功/失败原因）
5. 经验沉淀（可复用的方法论）
6. 问题清单（待优化项）
7. 改进计划（下一步行动）

格式：Markdown，结构清晰，可读性强。
```

### 📈 提效数据
- **传统耗时**：3-6小时
- **AI辅助耗时**：45分钟-1小时
- **效率提升**：80%
- **质量提升**：分析更深入，经验提炼更系统

## 任务5：社群运营管理

### 📌 任务定义
- **场景描述**：社群搭建、日常运营、活动策划、用户维护
- **输入要求**：社群定位、用户画像、运营目标
- **输出标准**：社群运营SOP + 话术库 + 活动日历

### 🤖 SOLO工作流
1. **定位设计**：明确社群价值和规则
2. **内容规划**：制定内容日历和话题库
3. **活动设计**：策划社群专属活动
4. **话术准备**：准备各类场景话术
5. **数据监测**：建立社群健康度指标

### 💡 最优Prompt
```
作为社群运营专家，请帮我制定社群运营方案。

【社群信息】
- 社群名称：{名称}
- 社群定位：{如学习型/交流型/服务型}
- 目标用户：{用户画像}
- 社群规模：{目标人数}

【运营目标】
- 核心目标：{如提升活跃度/促进转化}
- 关键指标：{如日活率、消息数、转化率}

【资源情况】
- 运营人员：{配置}
- 可用工具：{如企业微信/钉钉/微信群}
- 预算支持：{预算范围}

请输出完整运营方案：
1. 社群定位与价值主张
2. 社群规则（入群门槛、群规、退出机制）
3. 内容运营SOP（日/周/月内容日历）
4. 活动运营方案（常规活动+节点活动）
5. 用户分层运营策略
6. 场景话术库（欢迎话术、引导话术、危机处理话术等）
7. 数据监测体系
8. 运营排班表

格式：Markdown，可直接落地执行。
```

### 📈 提效数据
- **传统耗时**：6-12小时
- **AI辅助耗时**：1-2小时
- **效率提升**：85%
- **质量提升**：体系更完整，话术更专业

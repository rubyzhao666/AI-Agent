# 设计师 · AI 工作流（5 大核心任务）

## 任务1：设计需求理解

### 📌 任务定义
- **场景描述**：需求评审、项目启动、设计规划
- **输入要求**：需求文档、业务目标、用户场景
- **输出标准**：设计需求分析文档

### 🤖 SOLO工作流
1. **需求收集**：收集完整需求信息
2. **目标明确**：明确设计目标和约束
3. **场景梳理**：梳理用户使用场景
4. **问题定义**：定义设计要解决的问题
5. **方案规划**：规划设计方向

### 💡 最优Prompt
```
作为设计专家，请帮我分析和理解设计需求。

【项目背景】
- 项目名称：{项目名称}
- 项目类型：{如APP设计/网页设计/品牌设计}
- 业务背景：{为什么要做这个项目}

【需求描述】
{粘贴或描述需求内容}

【目标用户】
{用户画像和使用场景}

【业务目标】
{希望达成的业务指标}

【约束条件】
{时间、资源、技术等约束}

请输出：
1. 需求理解确认
   - 核心需求提炼
   - 需求优先级排序
   
2. 设计目标
   - 业务目标转化
   - 用户体验目标
   
3. 用户场景分析
   - 核心场景
   - 边缘场景
   
4. 设计约束
   - 时间约束
   - 技术约束
   - 品牌约束
   
5. 设计方向建议
   - 设计关键词
   - 参考风格
   - 关键设计点

6. 需要澄清的问题清单

格式：Markdown，结构清晰。
```

### 📈 提效数据
- **传统耗时**：1-2小时
- **AI辅助耗时**：20-30分钟
- **效率提升**：75%
- **质量提升**：理解更准确，返工减少50%

## 任务2：创意方案生成

### 📌 任务定义
- **场景描述**：创意发想、方案构思、头脑风暴
- **输入要求**：设计目标、品牌调性、参考方向
- **输出标准**：多个创意方向 + 方案描述

### 🤖 SOLO工作流
1. **信息输入**：整理设计背景信息
2. **创意发散**：多角度发散创意方向
3. **方案细化**：细化各方向方案
4. **优劣势分析**：分析各方案优劣势
5. **推荐建议**：给出推荐方向

### 💡 最优Prompt
```
作为创意设计专家，请帮我生成创意方案。

【设计任务】
- 设计类型：{如LOGO/海报/UI界面/品牌视觉}
- 设计主题：{主题描述}
- 应用场景：{使用场景}

【品牌信息】
- 品牌名称：{名称}
- 品牌定位：{定位}
- 品牌调性：{如专业/活力/高端/亲民}
- 品牌色：{如有}

【目标受众】
{用户画像}

【设计要求】
{具体的设计要求和约束}

【参考方向】
{喜欢的风格或参考案例}

请输出：
1. 创意方向一
   - 概念描述
   - 视觉风格
   - 关键元素
   - 优势分析
   - 适用场景

2. 创意方向二
   - 概念描述
   - 视觉风格
   - 关键元素
   - 优势分析
   - 适用场景

3. 创意方向三
   - 概念描述
   - 视觉风格
   - 关键元素
   - 优势分析
   - 适用场景

4. 方案对比与推荐

5. AI绘图Prompt建议（如适用）

格式：Markdown，描述生动具体。
```

### 📈 提效数据
- **传统耗时**：4-8小时
- **AI辅助耗时**：1-1.5小时
- **效率提升**：80%
- **质量提升**：创意更多元，方案更丰富

## 任务3：设计规范文档

### 📌 任务定义
- **场景描述**：设计系统建设、品牌规范、组件库
- **输入要求**：设计资产、使用场景、协作需求
- **输出标准**：完整设计规范文档

### 🤖 SOLO工作流
1. **资产盘点**：盘点现有设计资产
2. **规范框架**：确定规范文档结构
3. **内容编写**：编写各模块规范
4. **示例补充**：补充正确/错误示例
5. **版本管理**：建立版本更新机制

### 💡 最优Prompt
```
作为设计系统专家，请帮我编写设计规范文档。

【项目信息】
- 项目名称：{项目名称}
- 规范类型：{如品牌规范/UI规范/组件规范}
- 适用范围：{适用产品和团队}

【已有资产】
{描述现有的设计资产，如Logo、配色、字体、组件等}

【协作需求】
{团队协作中的痛点和需求}

请输出设计规范文档：
1. 概述
   - 规范目的
   - 适用范围
   - 使用指南

2. 品牌基础
   - Logo规范（使用规范、最小尺寸、安全区域、错误示例）
   - 品牌色（主色、辅助色、功能色、色值定义）
   - 字体规范（字体家族、字号层级、行高规范）

3. 设计原则
   - 设计价值观
   - 设计原则

4. 组件规范
   - 基础组件（按钮、输入框、图标等）
   - 业务组件
   - 每个组件包含：用法、状态、属性、示例

5. 布局规范
   - 栅格系统
   - 间距规范
   - 响应式规则

6. 动效规范
   - 动效原则
   - 时间曲线
   - 常用动效

格式：Markdown，结构清晰，可直接交付开发。
```

### 📈 提效数据
- **传统耗时**：20-40小时
- **AI辅助耗时**：3-5小时
- **效率提升**：85%
- **质量提升**：规范更系统，协作效率提升60%

## 任务4：设计评审反馈

### 📌 任务定义
- **场景描述**：设计评审、方案反馈、设计迭代
- **输入要求**：设计方案、评审标准、问题清单
- **输出标准**：结构化评审意见

### 🤖 SOLO工作流
1. **方案审阅**：审阅设计方案
2. **标准对照**：对照设计标准评审
3. **问题记录**：记录问题和建议
4. **优先级排序**：对问题进行优先级排序
5. **反馈输出**：输出评审反馈

### 💡 最优Prompt
```
作为设计评审专家，请帮我输出设计评审反馈。

【设计信息】
- 设计类型：{如UI设计/视觉设计/交互设计}
- 设计目标：{本次设计要达成的目标}
- 目标用户：{用户群体}

【设计方案】
{描述或粘贴设计方案内容}

【评审维度】
请从以下维度评审：
1. 视觉表现（美观度、品牌一致性）
2. 用户体验（易用性、可访问性）
3. 功能实现（需求覆盖、边界场景）
4. 技术可行性（实现难度、性能影响）
5. 创新性（创意亮点）

请输出：
1. 总体评价
   - 整体评分（1-10分）
   - 核心优点（3条）
   - 主要问题（3条）

2. 详细评审意见
   | 维度 | 评价 | 问题 | 建议 | 优先级 |
   |------|------|------|------|--------|
   | {维度} | {评价} | {问题} | {建议} | {P0/P1/P2} |

3. 必须修改项（P0）
   - 问题1：{描述}
     - 建议：{修改建议}
   
4. 建议优化项（P1）
   - 问题1：{描述}
     - 建议：{修改建议}

5. 可选改进项（P2）

6. 亮点肯定

格式：Markdown，反馈具体可执行。
```

### 📈 提效数据
- **传统耗时**：1-2小时
- **AI辅助耗时**：20-30分钟
- **效率提升**：75%
- **质量提升**：反馈更全面，沟通效率提升50%

## 任务5：作品集整理

### 📌 任务定义
- **场景描述**：求职面试、客户提案、作品归档
- **输入要求**：设计作品、项目背景、成果数据
- **输出标准**：结构化作品集

### 🤖 SOLO工作流
1. **作品筛选**：筛选代表性作品
2. **信息整理**：整理项目背景信息
3. **案例撰写**：撰写案例描述
4. **成果提炼**：提炼设计成果和价值
5. **排版优化**：优化作品集呈现

### 💡 最优Prompt
```
请帮我整理设计作品集案例描述。

【作品信息】
- 项目名称：{项目名称}
- 项目类型：{如APP设计/品牌设计/网页设计}
- 我的角色：{在项目中的角色}
- 项目时间：{时间}

【项目背景】
{描述项目背景和目标}

【设计过程】
{描述设计过程和方法}

【设计成果】
{描述最终设计方案}

【成果数据】
{如有数据支撑，如用户增长、转化提升等}

请输出作品集案例描述：
1. 项目概述（一句话亮点）
2. 项目背景
   - 业务背景
   - 设计挑战
   - 我的责任
   
3. 设计过程
   - 调研分析
   - 设计策略
   - 方案迭代
   
4. 设计方案
   - 核心设计点
   - 关键界面/视觉展示
   
5. 设计成果
   - 业务成果（数据支撑）
   - 设计亮点
   - 经验总结

字数：500-800字
格式：Markdown，适合作品集展示。
```

### 📈 提效数据
- **传统耗时**：2-4小时/案例
- **AI辅助耗时**：30-45分钟/案例
- **效率提升**：80%
- **质量提升**：描述更专业，亮点更突出

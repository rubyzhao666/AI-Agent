# 市场 · AI 工作流（5 大核心任务）

## 任务1：品牌传播方案

### 📌 任务定义
- **场景描述**：品牌升级、新品上市、品牌形象建设
- **输入要求**：品牌定位、目标受众、传播预算
- **输出标准**：完整品牌传播方案

### 🤖 SOLO工作流
1. **品牌诊断**：分析品牌现状和问题
2. **策略制定**：确定传播策略和核心信息
3. **创意发展**：发展创意概念和内容
4. **媒介规划**：规划传播渠道和节奏
5. **效果评估**：设计评估指标和方法

### 💡 最优Prompt
```
作为品牌营销专家，请帮我制定品牌传播方案。

【品牌信息】
- 品牌名称：{品牌名称}
- 品牌定位：{一句话定位}
- 品牌调性：{如专业/年轻/高端/亲民}

【传播背景】
- 传播目的：{如品牌升级/新品上市/品牌认知提升}
- 当前问题：{品牌面临的问题或挑战}

【目标受众】
- 核心人群：{年龄、职业、兴趣等}
- 媒介习惯：{常用媒体和平台}

【资源情况】
- 预算范围：{预算}
- 传播周期：{时间}
- 可用资源：{如代言人、IP、渠道等}

请输出完整传播方案：
1. 品牌现状诊断
2. 传播目标（认知/态度/行为目标）
3. 传播策略（核心信息、传播主题）
4. 创意方案（主视觉、Slogan、内容方向）
5. 媒介策略（渠道选择、投放节奏）
6. 内容规划（各平台内容矩阵）
7. 预算分配
8. 效果评估方案

格式：Markdown，创意与策略并重。
```

### 📈 提效数据
- **传统耗时**：16-40小时
- **AI辅助耗时**：3-4小时
- **效率提升**：85%
- **质量提升**：策略更系统，创意更丰富

## 任务2：市场调研报告

### 📌 任务定义
- **场景描述**：新品开发、市场进入、竞争分析
- **输入要求**：调研目标、调研范围、数据来源
- **输出标准**：结构化调研报告

### 🤖 SOLO工作流
1. **目标明确**：确定调研问题和假设
2. **方案设计**：设计调研方法和工具
3. **数据收集**：执行调研收集数据
4. **数据分析**：分析数据提炼洞察
5. **报告输出**：撰写调研报告

### 💡 最优Prompt
```
作为市场调研专家，请帮我设计调研方案并输出报告框架。

【调研背景】
- 调研目的：{如新品开发/市场进入/用户洞察}
- 业务问题：{需要回答的核心问题}

【调研范围】
- 目标市场：{市场/区域}
- 目标人群：{用户群体}
- 调研内容：{如用户需求、竞争格局、市场规模等}

【已有数据】
{如有现成数据，请描述或粘贴}

请输出：
1. 调研设计
   - 调研方法（定性/定量）
   - 样本设计
   - 调研工具（问卷/访谈提纲）
   
2. 调研报告框架
   - 执行摘要
   - 市场概况
   - 用户洞察
   - 竞争分析
   - 机会识别
   - 策略建议

3. 关键调研问题清单

格式：Markdown，专业规范。
```

### 📈 提效数据
- **传统耗时**：20-60小时
- **AI辅助耗时**：3-5小时
- **效率提升**：85%
- **质量提升**：调研设计更专业，洞察更深入

## 任务3：营销活动策划

### 📌 任务定义
- **场景描述**：促销活动、品牌活动、线上/线下活动
- **输入要求**：活动目标、预算、时间、资源
- **输出标准**：完整营销活动方案

### 🤖 SOLO工作流
1. **目标设定**：明确活动KPI
2. **创意策划**：设计活动主题和玩法
3. **执行规划**：制定执行计划和分工
4. **资源统筹**：协调各方资源
5. **效果评估**：设计评估体系

### 💡 最优Prompt
```
作为营销策划专家，请帮我策划营销活动方案。

【活动信息】
- 活动类型：{如促销活动/品牌活动/线上活动}
- 活动时间：{时间范围}
- 活动主题：{如有初步想法}

【活动目标】
- 核心KPI：{如销售额/参与人数/品牌曝光}
- 次要指标：{如转化率、客单价、分享率}

【资源情况】
- 预算：{预算范围}
- 渠道：{可用推广渠道}
- 支持：{设计、开发、客服等支持情况}

【目标用户】
{用户画像和消费行为}

请输出完整活动方案：
1. 活动概述（主题、时间、目标）
2. 活动创意（核心玩法、亮点设计）
3. 活动机制（参与规则、奖励机制）
4. 推广计划（渠道策略、投放节奏）
5. 执行计划（时间表、分工表）
6. 预算分配
7. 风险预案
8. 效果评估方案

格式：Markdown，可执行性强。
```

### 📈 提效数据
- **传统耗时**：8-20小时
- **AI辅助耗时**：1.5-2.5小时
- **效率提升**：85%
- **质量提升**：创意更丰富，执行更系统

## 任务4：媒体投放计划

### 📌 任务定义
- **场景描述**：广告投放、媒介采购、投放优化
- **输入要求**：投放目标、预算、目标人群
- **输出标准**：媒体投放方案 + 预算分配

### 🤖 SOLO工作流
1. **目标明确**：确定投放KPI
2. **人群分析**：分析目标人群媒介习惯
3. **渠道选择**：选择投放渠道组合
4. **预算分配**：分配各渠道预算
5. **效果预估**：预估投放效果

### 💡 最优Prompt
```
作为媒介投放专家，请帮我制定媒体投放计划。

【投放信息】
- 投放目的：{如品牌曝光/效果转化/用户增长}
- 投放周期：{时间范围}
- 投放预算：{总预算}

【目标人群】
- 人群画像：{年龄、性别、地域、兴趣等}
- 媒介习惯：{常用平台和内容偏好}

【产品信息】
{产品/服务介绍}

【历史数据】
{如有历史投放数据，请提供}

请输出：
1. 投放策略
   - 投放目标（曝光量/点击量/转化量）
   - 投放策略（品牌+效果组合）
   
2. 渠道规划
   - 渠道选择及理由
   - 各渠道预算分配
   - 各渠道投放形式

3. 创意规划
   - 创意方向
   - 素材需求清单

4. 投放节奏
   - 分阶段投放计划

5. 效果预估
   - 预估曝光/点击/转化
   - 预估ROI

6. 监测与优化方案

格式：Markdown，数据清晰。
```

### 📈 提效数据
- **传统耗时**：6-12小时
- **AI辅助耗时**：1-1.5小时
- **效率提升**：85%
- **质量提升**：策略更精准，预算分配更合理

## 任务5：危机公关预案

### 📌 任务定义
- **场景描述**：品牌危机、舆情事件、负面传播
- **输入要求**：风险识别、应对原则、资源清单
- **输出标准**：危机应对预案 + 话术库

### 🤖 SOLO工作流
1. **风险识别**：识别潜在危机场景
2. **预案制定**：制定各类危机应对预案
3. **流程设计**：设计危机响应流程
4. **话术准备**：准备各类回应话术
5. **演练计划**：制定预案演练计划

### 💡 最优Prompt
```
作为公关专家，请帮我制定危机公关预案。

【企业信息】
- 企业名称：{企业名称}
- 行业：{行业}
- 主要业务：{业务介绍}

【风险识别】
{列出可能面临的危机类型，如产品质量、数据安全、员工问题等}

【应对原则】
{企业危机应对的基本原则}

请输出：
1. 危机风险矩阵（风险类型+影响程度+发生概率）
2. 危机分级标准（一级/二级/三级）
3. 危机响应流程（发现-研判-响应-跟踪-复盘）
4. 组织架构（危机小组职责分工）
5. 各类危机应对预案
   - 产品质量危机
   - 数据安全危机
   - 舆情危机
   - 员工相关危机
6. 对外回应话术库
7. 媒体沟通指南
8. 预案演练计划

格式：Markdown，可操作性强。
```

### 📈 提效数据
- **传统耗时**：8-16小时
- **AI辅助耗时**：1.5-2小时
- **效率提升**：85%
- **质量提升**：预案更全面，响应更及时

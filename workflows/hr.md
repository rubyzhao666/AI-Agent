# HR · AI 工作流（5 大核心任务）

## 任务1：招聘JD撰写

### 📌 任务定义
- **场景描述**：新岗位招聘、岗位需求更新、人才盘点
- **输入要求**：岗位职责、任职要求、薪资范围、团队介绍
- **输出标准**：吸引人才的优质JD

### 🤖 SOLO工作流
1. **需求梳理**：与用人部门确认需求
2. **JD框架**：生成标准JD结构
3. **内容优化**：提升吸引力和专业度
4. **渠道适配**：适配不同招聘平台格式
5. **效果追踪**：建立JD效果评估指标

### 💡 最优Prompt
```
作为资深HR专家，请帮我撰写一份有吸引力的招聘JD。

【岗位信息】
- 岗位名称：{岗位名称}
- 所属部门：{部门}
- 汇报对象：{汇报对象}
- 编制类型：{全职/兼职/实习}
- 工作地点：{城市}

【岗位职责】
{描述主要工作内容}

【任职要求】
- 学历要求：{学历}
- 经验要求：{年限}
- 技能要求：{核心技能}
- 加分项：{优先考虑的条件}

【薪资福利】
- 薪资范围：{范围}
- 福利待遇：{如五险一金、年假、培训等}

【团队介绍】
{团队规模、氛围、亮点}

请输出JD：
1. 岗位亮点（3-5条吸引点）
2. 岗位职责（5-8条，具体可执行）
3. 任职要求（分必须项和加分项）
4. 我们提供（薪资福利亮点）
5. 团队介绍（有温度的描述）

要求：语言有吸引力，避免模板化，突出岗位价值。
```

### 📈 提效数据
- **传统耗时**：1-2小时
- **AI辅助耗时**：15-20分钟
- **效率提升**：80%
- **质量提升**：吸引力提升，简历转化率提高30%

## 任务2：面试评估表

### 📌 任务定义
- **场景描述**：面试流程设计、候选人评估、录用决策
- **输入要求**：岗位胜任力模型、面试轮次、评估维度
- **输出标准**：结构化面试评估表

### 🤖 SOLO工作流
1. **胜任力建模**：确定岗位核心能力要求
2. **题目设计**：设计行为面试题和情景题
3. **评分标准**：建立量化评分体系
4. **评估表生成**：输出标准化评估表
5. **面试官指南**：提供面试操作指引

### 💡 最优Prompt
```
作为招聘专家，请帮我设计结构化面试评估表。

【岗位信息】
- 岗位名称：{岗位名称}
- 岗位级别：{如P6/P7/M1等}
- 核心职责：{主要工作内容}

【胜任力要求】
{列出岗位需要的核心能力，如沟通能力、项目管理、专业技能等}

【面试安排】
- 面试轮次：{如一面/二面/三面}
- 每轮时长：{分钟}
- 面试官角色：{如HR/业务主管/高管}

请输出：
1. 岗位胜任力模型（能力维度+行为指标）
2. 结构化面试题库（每维度2-3道题，含STAR追问）
3. 评分标准（1-5分量化标准）
4. 面试评估表模板（含打分区、记录区、综合评价）
5. 面试官操作指南（注意事项、禁忌问题）

格式：Markdown，表格清晰，可直接打印使用。
```

### 📈 提效数据
- **传统耗时**：2-4小时
- **AI辅助耗时**：30-45分钟
- **效率提升**：80%
- **质量提升**：评估更客观，录用准确率提升25%

## 任务3：员工培训方案

### 📌 任务定义
- **场景描述**：新员工入职培训、技能提升培训、管理培训
- **输入要求**：培训目标、学员画像、时间安排、预算
- **输出标准**：完整培训方案 + 课程大纲

### 🤖 SOLO工作流
1. **需求分析**：确定培训需求和目标
2. **课程设计**：设计课程体系和内容大纲
3. **形式规划**：确定培训形式和时间安排
4. **资源准备**：讲师、教材、场地等
5. **效果评估**：设计培训效果评估方案

### 💡 最优Prompt
```
作为培训专家，请帮我设计员工培训方案。

【培训背景】
- 培训类型：{如新员工培训/技能培训/管理培训}
- 培训目标：{具体要达成的目标}
- 目标学员：{人数、岗位、背景}

【培训需求】
{描述学员当前存在的问题或需要提升的能力}

【资源约束】
- 培训时长：{总时长}
- 培训形式：{线上/线下/混合}
- 预算范围：{预算}
- 可用资源：{内部讲师/外部资源等}

请输出完整培训方案：
1. 培训目标（知识目标+技能目标+态度目标）
2. 课程体系（模块划分+时间分配）
3. 详细课程大纲（每模块内容+教学方法）
4. 培训日程安排
5. 资源需求清单（讲师、教材、场地、设备）
6. 考核评估方案（过程评估+结果评估）
7. 培训效果追踪方案

格式：Markdown，结构清晰，可执行性强。
```

### 📈 提效数据
- **传统耗时**：8-16小时
- **AI辅助耗时**：1.5-2小时
- **效率提升**：85%
- **质量提升**：课程设计更系统，培训效果提升40%

## 任务4：绩效考核表

### 📌 任务定义
- **场景描述**：季度/年度考核、试用期评估、晋升评估
- **输入要求**：岗位目标、考核周期、评估维度
- **输出标准**：量化绩效考核表

### 🤖 SOLO工作流
1. **目标拆解**：将部门目标拆解到个人
2. **指标设计**：设计KPI/OKR指标
3. **权重分配**：确定各指标权重
4. **评分标准**：建立量化评分规则
5. **表单生成**：输出标准化考核表

### 💡 最优Prompt
```
作为绩效管理专家，请帮我设计绩效考核表。

【考核对象】
- 岗位名称：{岗位名称}
- 岗位级别：{级别}
- 所属部门：{部门}

【考核周期】
- 周期：{月度/季度/年度}
- 时间范围：{起止时间}

【岗位目标】
{描述该岗位的核心职责和目标}

【考核维度】
{如业绩指标、能力指标、态度指标等}

请输出：
1. 考核指标体系（指标+权重+目标值+评分标准）
2. 绩效考核表模板
3. 自评区（工作成果+亮点+不足）
4. 上级评价区（评分+评语）
5. 综合评定区（等级+建议）
6. 绩效面谈指南

格式：Markdown，表格清晰，可直接使用。

示例表格格式：
| 指标类别 | 指标名称 | 权重 | 目标值 | 实际值 | 评分 | 说明 |
```

### 📈 提效数据
- **传统耗时**：2-4小时
- **AI辅助耗时**：30-45分钟
- **效率提升**：80%
- **质量提升**：指标更量化，考核更公平

## 任务5：薪酬分析报告

### 📌 任务定义
- **场景描述**：年度调薪、薪酬对标、成本分析、激励方案
- **输入要求**：薪酬数据、市场对标、预算约束
- **输出标准**：数据分析报告 + 调整建议

### 🤖 SOLO工作流
1. **数据收集**：整理内部薪酬数据
2. **市场对标**：获取市场薪酬数据
3. **差异分析**：分析内外部薪酬差距
4. **方案设计**：设计调薪或激励方案
5. **成本测算**：测算方案成本和影响

### 💡 最优Prompt
```
作为薪酬专家，请帮我完成薪酬分析报告。

【分析背景】
- 分析目的：{如年度调薪/薪酬对标/成本控制}
- 分析范围：{部门/岗位/全员}

【薪酬数据】
{粘贴或描述薪酬数据，如：
- 平均薪酬：{金额}
- 薪酬结构：{基本工资/绩效/奖金占比}
- 薪酬分布：{分位值数据}
}

【市场数据】
{如有市场对标数据，请提供}

【分析要求】
请从以下维度分析：
1. 薪酬结构分析
2. 内部公平性分析
3. 外部竞争力分析
4. 成本分析
5. 问题诊断

请输出：
1. 执行摘要
2. 薪酬现状分析（含数据图表建议）
3. 市场对标分析
4. 问题诊断
5. 调整建议（调薪方案/激励优化）
6. 成本测算
7. 实施建议

格式：Markdown，数据呈现清晰。
```

### 📈 提效数据
- **传统耗时**：6-12小时
- **AI辅助耗时**：1-2小时
- **效率提升**：85%
- **质量提升**：分析更深入，建议更有数据支撑

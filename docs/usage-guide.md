## 🎯 使用指南

### 第一步：选择岗位
根据你的职业角色，定位到对应岗位章节。

### 第二步：识别任务
查看该岗位的5大核心任务，找到当前需要完成的任务。

### 第三步：复制Prompt
复制对应任务的最优Prompt模板。

### 第四步：填充信息
将你的具体信息填入Prompt中的`{占位符}`位置。

### 第五步：生成输出
将填充完整的Prompt发送给AI，获取输出结果。

### 第六步：优化迭代
根据输出结果进行优化调整，形成最终交付物。

## 💡 进阶使用技巧

### 1. Prompt组合使用
多个任务的Prompt可以组合使用，形成完整工作流。
```
示例：产品经理新功能开发
1. 先用「竞品分析」Prompt了解市场
2. 再用「需求文档」Prompt撰写PRD
3. 最后用「用户故事」Prompt拆解任务
```

### 2. 迭代优化
首次输出后，可以追问优化：
- "请优化第3部分，增加更多细节"
- "请用更简洁的语言重写"
- "请增加数据支撑"

### 3. 个性化定制
将Prompt保存为个人模板，根据工作习惯调整：
- 添加公司特有的格式要求
- 加入行业专业术语
- 融入团队协作规范

### 4. 效果追踪
记录使用前后的时间对比，持续优化Prompt：
- 记录实际耗时
- 评估输出质量
- 积累优化经验
